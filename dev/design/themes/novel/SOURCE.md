# novel

- In-house theme for novel-writer, not a company clone. Grounded on the project's
  real neutral grayscale palette (black primary) and a coherent editorial reading scale.
- Viewport: 1440×900, page scale 100%
- Font: Inter Variable → Inter + Noto Sans KR
- `.dark` overrides colors only; fonts, radius, shadows, and spacing live on `:root`.
- Theme: `layout.css` (compiled into drafts that set `data-layout-css`)

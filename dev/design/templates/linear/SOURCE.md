# linear

- Live URL: https://linear.app/
- Viewport: 1440×900, page scale 100%
- Font: Inter Variable → Inter + Noto Sans KR
- `.dark` is the measured homepage. `:root` is a light counterpart so the draft scheme toggle can switch modes. Fonts, radius, and shadows stay on `:root`.
- Theme: `layout.css` (compiled into drafts that set `data-layout-css`)
